# toritoritori
とりを飼っているドラゴンガールと、肩や頭やつのに止まりにくるとりたちのゴースト  
「とり、籠に入りやしない」です。


ダウンロードは以下のリンクからできます。  
https://github.com/Shimofumi/toritoritori/releases

一番上のバージョンのAssetsの欄から「toritoritori.nar」をダウンロードしてSSP最新版にドラッグアンドドロップして導入してください。  
ゴーストマスカレード8版を導入済みの方も、同じ手順で上書きして更新できます。

ダウンロードできるものは細かな更新が反映されていないので、  
ゴースト導入後、右クリックでネットワーク更新をしてください。
